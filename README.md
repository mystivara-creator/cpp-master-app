# C++ Master (Belajar C++ dari Dasar hingga Mahir) 🚀

Aplikasi Android interaktif berbahasa Indonesia untuk mempelajari pemrograman C++ dari nol hingga mahir, dilengkapi dengan kuis interaktif, tantangan koding harian (*daily coding challenges*), serta *code playground* interaktif.

---

## 📱 Cara Download & Pasang APK Langsung ke HP (Tanpa ZIP!)

Sekarang Anda bisa langsung mendownload file `.apk` murni tanpa perlu mengekstrak ZIP atau memakai ZArchiver:

1. Buka repository ini di browser HP Anda.
2. Di halaman utama repository (bagian sebelah kanan atau gulir ke bawah), ketuk menu **Releases** (atau langsung buka link `https://github.com/USERNAME/cpp-master-app/releases`).
3. Pada rilis terbaru (*Latest*), ketuk file **`CppMaster.apk`** di bagian *Assets*.
4. File `.apk` akan langsung terunduh secara utuh ke HP Anda.
5. Ketuk file yang baru selesai diunduh untuk langsung memasang aplikasi!

---

## 📚 Kurikulum yang Tersedia di Aplikasi

- **Tingkat 1: Dasar C++** (6 Modul): Pengenalan, Struktur `main()`, Tipe Data, Operator, Percabangan `if-else`, Perulangan `for/while`, Array & `std::vector`.
- **Tingkat 2: Menengah C++** (6 Modul): Fungsi & Referensi `&`, Pointer & Memori, Alokasi Dinamis (`new`/`delete`), `struct` & `enum class`, Pemrograman Berorientasi Objek (OOP: Class, Constructor, Destructor), serta Enkapsulasi.
- **Tingkat 3: Mahir C++** (7 Modul): Pewarisan (*Inheritance*), Polimorfisme & Virtual Functions, Operator Overloading, Templates, Smart Pointers (`std::unique_ptr`, RAII), STL Containers (`std::map`, `std::sort`), serta Modern C++ (Lambda & Move Semantics).

## ⚡ Fitur Interaktif Lainnya

- **Tantangan Koding Harian**: Rotasi soal algoritma setiap hari dengan penguji *test cases* otomatis dan sistem *streak* (🔥).
- **Kuis Interaktif**: Kuis Kilat (Speed Quiz), Ujian Tingkat Penguasaan, dan Kuis Bab dengan umpan balik instan.
- **Playground C++**: Tempat mencoba dan mengeksekusi kode C++ bebas dengan template bawaan dan konsol terminal.
- **Profil & Gamifikasi**: Poin XP, tingkatan level programmer, dan lencana prestasi (*badges*).
